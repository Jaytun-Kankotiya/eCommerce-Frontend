# 🛍️ Full-Stack E-commerce Frontend

A feature-rich e-commerce frontend that powers the platform where users can **browse, search, view, and purchase products**.  
This project demonstrates a complete **full-stack workflow** with secure user authentication, product management, and RESTful API design.

---

## 🚀 Demo Link

🔗 [Live Demo](https://e-commerce-frontend-alpha-flax.vercel.app/)

## ⚙️ Quick Start

```bash
# Clone the repository
git clone https://github.com/Jaytun-Kankotiya/eCommerce-Frontend.git

# Navigate to the project directory
cd Ecommerce Frontend

# Install dependencies
npm install

# Start the server
npm run dev   # or yarn dev

```

**Technologies Used:**

- **Framework:** React(Vite),
- **State Management:** Context API
- **Styling:** Bootstrap
- **Routing:** React Router
- **Notifications:** React Toastify
- **Persistence:** LocalStorage

## Features

**🏠 Home Page**

- Browse and explore products by category — including New Arrivals, Sale, Offers, Men, Women, and Kids — for a personalized shopping experience.
- Search products by name or keyword
- Responsive and dynamic product grid layout

**🛍️ Products Page**

- Browse products organized into various categories (e.g., Men, Women, Kids, Accessories).
- Apply filters to narrow down products based on category, price, or other preferences.

**📄 Product Details Page**

- View detailed product information, including description, available sizes, price, and ratings.
- Get personalized product recommendations.
- Add items directly to the **cart** for purchase or to the **wishlist** for future reference.

**💖 Wishlist**

- Add or remove products from wishlist
- Persistent wishlist across pages

**🛒 Cart**

- Add, update, or remove items from the cart
- Adjust quantities and view total cost
- View delivery charges and estimated total

**🧾 Checkout & Address**

- Add and save multiple delivery addresses
- Use saved addresses during checkout
- Display default address if available

**🔐 Authentication**

- User signup and login via backend JWT authentication
- Redirects protected pages if user is not logged in

**📦 Orders**

- View past orders and order details

---

**📱 Responsive Design**

- Built with Tailwind CSS for a fully responsive layout across all devices — mobile, tablet, and desktop.
